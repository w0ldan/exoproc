Oracle, Java 15 sürümünden itibaren Nashorn JavaScript motorunu kaldırmış olsa da, Exoproc'un **`njava-runtime`** paketi Nashorn ekosistemini modern TypeScript ve ES2024 yetenekleriyle baştan inşa ederek Java 8'den Java 25+'e kadar tüm sürümlerde yüksek performanslı betik çalıştırma desteği sunar.

`exoproc run <script.ts>` komutuyla veya TypeScript uygulamalarınızın içine gömülü olarak çalıştırılan betikler, hedef Java nesnelerine yerel JavaScript değişkenleriymiş gibi doğrudan erişebilir.

```text
TypeScript Otomasyon Betiği (script.ts)
                    │
                    ▼
          njava-runtime Motoru
  ┌─────────────────────────────────────┐
  │ Önceden Tanımlı Değişkenler:        │
  │ • Java (Nashorn uyumluluk katmanı)  │
  │ • print / console                   │
  │ • mc (Hedef istemci örneği)         │
  │ • currentScreen                     │
  └─────────────────────────────────────┘
                    │
                    ▼
           Canlı Hedef JVM
```

## Betik Çalıştırma: `exoproc run`

Bağlı olan Minecraft veya Java sürecine karşı dilediğiniz betiği çalıştırın:

```bash
# Yerel otomasyon betiğini çalıştır
exoproc run my-bot.ts

# Özel parametreler veya hedef PID ile çalıştır
exoproc run --pid 12345 scripts/mine.ts
```

## Nashorn Uyumluluk Katmanı (Shims)

`JavaContext`, eski Nashorn betikleriyle birebir aynı genel değişkenleri sağlayarak eski Minecraft botlarını modern V8/Bun hızlarına taşır:

### 1. `Java.type(className)`

Statik sınıfları çözer ve kurucu fonksiyonlarla örnek oluşturulmasını sağlar:

```typescript
const ArrayList = Java.type('java.util.ArrayList');
const list = new ArrayList();
list.add('Elmas Kılıç');
list.add('Altın Elma');
console.log(list.size()); // 2
```

### 2. `Java.from(javaCollectionOrArray)`

Java listelerini, kümelerini ve yerel dizilerini standart JavaScript dizilerine dönüştürür:

```typescript
const players = Java.from(mc.theWorld.playerEntities);
players.forEach((p) => {
  console.log(
    `Oyuncu: ${p.getName()} konum: (${p.posX}, ${p.posY}, ${p.posZ})`,
  );
});
```

### 3. `Java.to(jsArray, javaType)`

JavaScript dizilerini tipli Java dizilerine dönüştürür:

```typescript
const jsNumbers = [10, 20, 30, 40];
const javaIntArray = Java.to(jsNumbers, 'int[]');
```

### 4. `Java.extend(superType, implementations)`

Java arayüzlerini veya soyut sınıflarını doğrudan JavaScript nesneleriyle uygular:

```typescript
const Runnable = Java.type('java.lang.Runnable');

const MyTask = Java.extend(Runnable, {
  run: () => {
    print('Görev JavaScript geri çağrımı içinden çalıştırıldı!');
  },
});

const taskInstance = new MyTask();
taskInstance.run();
```

## Otomatik Hata Ayrıştırma (Exception Unwrapping)

Standart JNI veya yansıma çağrılarında Java istisnaları derin `InvocationTargetException` katmanları altına gömülür ve hatanın asıl kaynağı gizlenir.

`njava-runtime`, fırlatılan Java hatalarını otomatik olarak inceler, asıl kök nedeni ayıklar ve yerel bir JavaScript `Error` nesnesine dönüştürür:

```typescript
try {
  const BadClass = Java.type('olmayan.bir.Sinif');
} catch (err: any) {
  // Doğrudan standart JavaScript hatası olarak yakalanır
  console.error(err.message); // "ClassNotFoundException: olmayan.bir.Sinif"
}
```

## Programatik Betik Çalıştırıcı API

Betik çalıştırıcıyı kendi özel araçlarınızın içinde doğrudan kod ile de kullanabilirsiniz:

```typescript
import { ScriptRunner } from 'njava-runtime';

const runner = new ScriptRunner({
  context: javaContext,
  globals: {
    customConfig: { speed: 1.5 },
  },
});

const result = await runner.execute(`
  const mc = Java.type('net.minecraft.client.Minecraft').getMinecraft();
  print("Aktif oyuncu: " + mc.thePlayer.getName());
`);
```
