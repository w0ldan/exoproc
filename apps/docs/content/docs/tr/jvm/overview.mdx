Exoproc, çalışan bir Windows sürecindeki Java Sanal Makinesi'ni (JVM) doğrudan TypeScript veya JavaScript ortamından incelemek, yönetmek ve tersine mühendislik uygulamak için kapsamlı bir katman sunar (`bun-njava`, `njava-agent`, `njava-runtime`).

Bu sistem sayesinde herhangi bir DLL enjekte etmeden veya Java ajan dosyası (`.jar`) diske yazmadan hedef JVM'deki sınıflara, nesnelere ve metodlara doğrudan erişebilirsiniz.

```text
TypeScript / Bun (Otomasyon veya Script)
                    │
               JavaContext
         (Nashorn / GraalJS API)
                    │
     ┌──────────────┴──────────────┐
     ▼                             ▼
ReflectionBridge              AgentReflectionBridge
(Sıfır Enjeksiyon / JNI)      (In-Process njava-agent)
     │                             │
Bellek & VTable Çağrıları      Yüksek Hızlı HTTP RPC
     │                             │
     └──────────────┬──────────────┘
                    ▼
          Hedef JVM (jvm.dll)
       (Minecraft / Java Süreci)
```

## İki Temel Köprü Modeli

Exoproc, hedefin güvenlik kısıtlamalarına ve performans gereksinimlerine göre iki farklı köprü mimarisi sağlar:

| Özellik                | ReflectionBridge (Saf JNI)                                      | AgentReflectionBridge (In-Process Agent)                               |
| ---------------------- | --------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **Enjeksiyon**         | Sıfır enjeksiyon (ne DLL ne JAR)                                | Bellek içi bytecode enjeksiyonu (`defineClass`)                        |
| **Gizlilik (Stealth)** | Tam gizlilik; süreç belleğinde yabancı thread veya modül yoktur | Hedef süreç içinde yerleşik HTTP/RPC sunucusu çalışır                  |
| **Çalışma Modeli**     | `jvm.dll` üzerinden doğrudan `JNIEnv` vtable çağrıları          | Yerel soket üzerinden yüksek hızlı JSON/Binary RPC                     |
| **Performans**         | Tekil sorgulamalar ve inceleme için ideal                       | Yüksek frekanslı çağrılar ve döngüler için optimize                    |
| **Özel Özellikler**    | JNI vtable marshalling, uzaktan nesne handle yönetimi           | `Java.runOn` ile oyun/ana thread yönlendirmesi, anlık bytecode derleme |

### 1. ReflectionBridge (Saf JNI)

`ReflectionBridge`, hedef sürecin belleğindeki `jvm.dll` modülünü tespit eder, `JNI_GetCreatedJavaVMs` sembolünü çözer ve sanal makinenin `JNIEnv` vtable fonksiyonlarını doğrudan cross-process çağırır.

- Hedef JVM içerisine yeni bir thread açılmaz (`CreateRemoteThread` kullanılmaz).
- `FindClass` kısıtlamalarını aşmak için `java.lang.Class.forName` ve `ClassLoader` yolları dinamik vtable zinciri üzerinden başlatılır.
- Anticheat veya bütünlük denetimi olan süreçlerde sıfır iz bırakarak inceleme yapmak için idealdir.

### 2. AgentReflectionBridge (In-Process Agent)

Hedef süreçte yüksek frekanslı metod çağrıları yapmak (örneğin Minecraft içinde her oyun tick'inde yüzlerce nesneyi okumak) gerektiğinde JNI IPC maliyetini sıfırlamak için `njava-agent` devreye girer.

- Bellek içi bytecode enjeksiyonu (`ClassLoader.defineClass`) ile hedefe yüklenir.
- Geliştirici ortamıyla localhost üzerinden haberleşir.
- `Java.runOn(executor, fn)` desteğiyle çağrıları doğrudan hedef uygulamanın ana thread'ine (örneğin Render veya Tick thread) yönlendirebilir.

## Hızlı Başlangıç

Hedef sürece bağlanmak ve bir `JavaContext` elde etmek için temel akış:

```typescript
import { Process } from 'bun-winapi';
import { RemoteCallableMemoryAccessor } from 'bun-xffi';
import { attachJvm, createJavaContext } from 'bun-njava';

// 1. Hedef sürece bağlan
const process = Process.findByName('javaw.exe');
const memory = new RemoteCallableMemoryAccessor(process.pid);

// 2. JVM köprüsünü oluştur (Saf JNI)
const bridge = await attachJvm(memory);

// 3. Nashorn/GraalJS uyumlu JavaContext oluştur
const Java = createJavaContext(bridge);

// 4. Sınıflara ve nesnelere eriş
const System = Java.type('java.lang.System');
const javaVersion = System.getProperty('java.version');
console.log(`Hedef JVM Sürümü: ${javaVersion}`);
```

## Senkron ve Asenkron Yürütme

`JavaContext`, hem senkron hem de asenkron programlama modellerini destekler:

- **Senkron Kip (`Java.asSync()`):** Çağrılar anında değer döndürür (`const res = myObj.getName()`). TypeScript otomasyon betikleri için en ergonomik modeldir.
- **Asenkron Kip (`Java.asAsync()`):** Her yansıma çağrısı bir Promise döner (`const res = await myObj.getName()`).

Ayrıca mevcut bir JNI bağlantısını dilediğiniz an agent moduna yükseltebilirsiniz:

```typescript
// Saf JNI köprüsünden bellek içi Ajan köprüsüne geçiş
const agentJava = await Java.transitionToAgent();
```
