Java ortamındaki veri yapıları (`List`, `Set`, `Collection`, Java dizileri) ile JavaScript dizileri (`Array`) arasında akıcı bir köprü kurmak için `Java.from()` ve `Java.to()` fonksiyonları kullanılır.

Bu yardımcılar, Nashorn ve GraalJS standartlarına tam uyumludur.

## Java'dan JavaScript'e: `Java.from()`

`Java.from(javaObj)` fonksiyonu:

- Herhangi bir Java `List`, `Collection`, `Iterable` nesnesini veya Java dizisini yerel bir JavaScript dizisine (`Array<any>`) dönüştürür.
- Liste içindeki her eleman otomatik olarak uygun JavaScript tipine veya `JavaObjectProxy` nesnesine çözümlenir.
- JavaScript'in yerleşik `.map()`, `.filter()`, `.forEach()` ve `for...of` döngüleriyle doğrudan kullanılabilir hale gelir.

```typescript
const ArrayList = Java.type('java.util.ArrayList');
const list = new ArrayList();

list.add('Elma');
list.add('Armut');
list.add('Muz');

// Java List nesnesini yerel JS Array'e dönüştür
const jsList = Java.from(list);

console.log(Array.isArray(jsList)); // true
console.log(jsList.length); // 3

// Standart JS dizi metodları
const buyukHarfler = jsList.map((item) => item.toUpperCase());
console.log(buyukHarfler); // ['ELMA', 'ARMUT', 'MUZ']
```

### Java Dizilerinin Dönüştürülmesi

Java ortamından dönen nesne dizileri (`String[]`, `Object[]`) veya ilkel veri dizileri (`int[]`, `byte[]`) de aynı şekilde `Java.from()` ile dönüştürülür:

```typescript
const StringClass = Java.type('java.lang.String');
const metin = new StringClass('merhaba dünya exoproc');

// Java split metodu String[] döner
const javaDizi = metin.split(' ');

// JavaScript dizisine çevir
const jsKelimeler = Java.from(javaDizi);
console.log(jsKelimeler); // ['merhaba', 'dünya', 'exoproc']
```

## JavaScript'ten Java'ya: `Java.to()`

`Java.to(jsArray, targetType)` fonksiyonu, JavaScript dizilerini hedef JVM'de geçerli bir Java dizisine veya koleksiyonuna dönüştürür.

### 1. Nesne Dizileri Oluşturma

Hedef sınıf tipi belirtilerek `String[]` veya özel sınıf dizileri oluşturulabilir:

```typescript
// Java String[] dizisi üret
const javaStringDizisi = Java.to(
  ['alpha', 'beta', 'gamma'],
  'java.lang.String[]',
);

// Hedef tip belirtilmezse varsayılan olarak Object[] üretilir
const varsayilanDizi = Java.to(['bir', 2, true]);
```

### 2. İlkel (Primitive) Diziler Oluşturma

JVM'de yüksek performanslı tamponlar veya dosya/ağ işlemleri için ilkel diziler (`byte[]`, `int[]`, `float[]`, vb.) gereklidir. `Java.to()` bu dönüşümü otomatik olarak yapar:

```typescript
// İlkel byte[] oluştur
const byteDizisi = Java.to([0x1f, 0x8b, 0x08], 'byte[]');

// İlkel int[] oluştur
const intDizisi = Java.to([100, 200, 300, 400], 'int[]');

// İlkel double[] oluştur
const doubleDizisi = Java.to([1.25, 3.1415, 9.8], 'double[]');
```

### 3. Koleksiyonlara Dönüştürme

Dizi yerine `List` veya `ArrayList` talep edildiğinde tip olarak koleksiyon adı verilebilir:

```typescript
const javaListesi = Java.to(['a', 'b', 'c'], 'java.util.ArrayList');
console.log(javaListesi.size()); // 3
```

## JNI Bellek Yönetimi

`Java.to()` çağrıldığında:

1. `ReflectionBridge` arka planda uygun JNI fonksiyonunu (`NewObjectArray`, `NewIntArray`, `NewByteArray`, vb.) çağırarak hedef JVM yığınında (heap) dizi tahsis eder.
2. Dizi elemanları hedef belleğe yazılır (`SetObjectArrayElement` veya `SetIntArrayRegion`).
3. Dönen nesne bir `JavaObjectProxy` olarak sarmalanıp çağıran koda teslim edilir.
