Enjekte edilecek Java kodları veya gelişmiş otomasyon betikleri geliştirirken, yazılan özel sınıfların hedef uygulamanın tiplerine (örneğin Minecraft'ın `Minecraft`, `EntityPlayerSP` veya `WorldClient` sınıfları) erişmesi gerekir. Ancak oyunun orijinal JAR dosyaları genellikle karartılmıştır (obfuscated), yüzlerce megabayt boyutundadır veya geliştirme ortamında doğrudan bulunmaz.

Exoproc, bu sorunu haritalama şemalarından veya canlı JVM yansımasından temiz, hafif Java ve TypeScript taslakları (stubs) üreten **`JavaStubProject`** mimarisi ile çözer.

```text
Oyun Haritaları / Canlı Yansıma
               │
               ▼
        JavaStubProject
  ┌────────────────────────────────────┐
  │  src/main/java/                    │  (Üretilen .java taslakları)
  │  build/classes/java/main/          │  (Gömülü ECJ ile derlenmiş)
  │  build/libs/stubs.jar              │  (Paketlenmiş classpath JAR'ı)
  │  typings/game.d.ts                 │  (TypeScript tip tanımları)
  └────────────────────────────────────┘
               │
      ┌────────┴────────┐
      ▼                 ▼
compileJava() İçin    Eksiksiz TypeScript
   Sınıf Yolu           IDE Otomatik Tamamlama
```

## Sanal Bir Çalışma Alanı Oluşturma

İster geçici bir dizinde ister projenizin altında doğrudan bir `JavaStubProject` başlatabilirsiniz:

```typescript
import { JavaStubProject } from 'bun-njava';

const project = new JavaStubProject({
  javaVersion: 8,
});

console.log('Çalışma alanı dizini:', project.workspaceDir);
console.log('Hedef taslak JAR yolu:', project.jarPath);
```

## Sınıf Ekleme ve Kaynak Kod Üretimi

Sınıflar şema tanımları üzerinden kaydedilebilir veya bilinen standart oyun sınıfları kataloğundan seçilebilir:

```typescript
// Sınıf şemasını kaydet
project.addClassSchema({
  className: 'net.minecraft.client.Minecraft',
  superClass: 'java.lang.Object',
  interfaces: [],
  fields: [
    {
      name: 'thePlayer',
      type: 'net.minecraft.client.entity.EntityPlayerSP',
      isStatic: false,
    },
    {
      name: 'theWorld',
      type: 'net.minecraft.client.multiplayer.WorldClient',
      isStatic: false,
    },
  ],
  methods: [
    {
      name: 'getMinecraft',
      returnType: 'net.minecraft.client.Minecraft',
      params: [],
      isStatic: true,
    },
    { name: 'runTick', returnType: 'void', params: [], isStatic: false },
  ],
});

// src/main/java/ dizinine Java kaynak kodlarını üret
project.generateSources();
```

## Derleme ve `stubs.jar` Oluşturma

`JavaStubProject`, gömülü ECJ derleyicisini çalıştırarak `.class` dosyalarını derler ve bunları tek bir kompakt JAR dosyasında toplar:

```typescript
// Tüm taslakları build/libs/stubs.jar içerisine derle
const result = await project.compile();

if (result.success) {
  console.log(`Taslaklar başarıyla derlendi: ${project.jarPath}`);
}
```

## Enjekte Edilen Kodları Taslaklara Karşı Derleme

`stubs.jar` üretildikten sonra, `compileJava()` çağrısına bir `classpath` girdisi olarak iletilebilir. Artık özel Java sınıflarınız gerçek Minecraft istemcisine ihtiyaç duymadan oyun tiplerinden miras alabilir veya bu tipleri referans gösterebilir:

```typescript
import { compileJava } from 'bun-njava';

const myInjectedSource = `
package org.exoproc.injected;

import net.minecraft.client.Minecraft;
import net.minecraft.client.entity.EntityPlayerSP;

public class ChatNotifier implements Runnable {
    @Override
    public void run() {
        Minecraft mc = Minecraft.getMinecraft();
        if (mc.thePlayer != null) {
            mc.thePlayer.sendChatMessage("Exoproc Bot Başlatıldı.");
        }
    }
}
`;

const buildResult = await compileJava({
  source: myInjectedSource,
  classpath: [project.jarPath], // Üretilen taslak JAR'ını kullanın!
  javaVersion: 8,
});
```

## TypeScript `.d.ts` Tip Tanımları Üretme

TypeScript betiklerinizde `Java.type()` çağrılarında eksiksiz otomatik tamamlama (IntelliSense) elde etmek için tip bildirim dosyası üretebilirsiniz:

```typescript
// Kayıtlı tüm Java tiplerini içeren .d.ts içeriğini üret
const dtsContent = project.generateTypeDeclarations();
await Bun.write('types/minecraft.d.ts', dtsContent);
```

Böylece kod editörünüzde `Java.type('net.minecraft.client.Minecraft').getMinecraft()` yazdığınızda tüm metot parametreleri, özellikler ve dönüş tipleri otomatik olarak listelenir!
