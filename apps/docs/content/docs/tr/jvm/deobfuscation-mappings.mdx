---

Birçok ticari Java uygulaması ve özellikle vanilya Minecraft sürümleri, ProGuard veya benzeri araçlarla karıştırılmış (obfuscated) kod yapılarına sahiptir. Sınıf adları `ave`, alan adları `h`, metod adları ise `a` gibi anlamsız kısaltmalara dönüştürülür.

Exoproc, çalışma zamanında bu karmaşayı ortadan kaldırmak için **`JavaMappingRegistry`** mimarisini sunar. Geliştirici temiz, anlaşılır isimler yazarken; Exoproc arka planda doğru karıştırılmış sembolleri çözümler.

## Çalışma Prensibi

```text
Geliştirici Kodu (TypeScript)
const mc = Java.type('net.minecraft.client.Minecraft').getMinecraft();
mc.thePlayer.sendChatMessage('Selam!');
                          │
                          ▼
             JavaMappingRegistry
  ┌────────────────────────────────────────────────────────┐
  │ net.minecraft.client.Minecraft ──► ave                 │
  │ getMinecraft()                 ──► A()                 │
  │ thePlayer                      ──► h                   │
  │ sendChatMessage()              ──► e()                 │
  └────────────────────────────────────────────────────────┘
                          │
                          ▼
            Hedef JVM Çalışma Zamanı
ave.A().h.e("Selam!");
```

## Manuel Eşleme Tanımlama: `Java.mapClass()`

Küçük ölçekli projeler veya özel yamalar için eşlemeler doğrudan kod üzerinden kaydedilebilir:

```typescript
// Sınıfı ve üyelerini eşle
Java.mapClass('ave', 'net.minecraft.client.Minecraft', {
  fields: {
    h: 'thePlayer',
    f: 'theWorld',
    u: 'gameSettings',
  },
  methods: {
    A: 'getMinecraft',
    s: 'runTick',
  },
});

// Ayrı alan ve metod eşlemeleri ekleme
Java.mapField('ave', 'm', 'currentScreen');
Java.mapMethod('ave', 'g', 'toggleFullscreen');
```

Eşleme tanımlandıktan sonra `Java.type` doğrudan deobfuscated ismi kabul eder:

```typescript
const Minecraft = Java.type('net.minecraft.client.Minecraft');
const mc = Minecraft.getMinecraft();

// Deobfuscated alan erişimi
console.log('Mevcut ekran:', mc.currentScreen);

// Deobfuscated metod çağrısı
mc.toggleFullscreen();
```

## Eşleme Havuzları (Mapping Pools) ile Entegrasyon

Büyük ölçekli projelerde (örneğin Minecraft otomasyonu) binlerce sınıfı tek tek eşlemek yerine **`exoproc-mappings`** (veya `njava-mappings`) veritabanları kullanılır.

Exoproc; **Mojang Official**, **Fabric Yarn**, **MCP (Mod Coder Pack)** ve **Intermediary** formatlarını destekler:

```typescript
import { JavaMappingRegistry } from 'bun-njava';
import { loadMojangMappings } from 'exoproc-mappings';

// 1. Mojang resmi eşleme tablosunu yükle
const mappings = await loadMojangMappings('1.20.4');

// 2. Mapping registry'yi başlat
const mapper = new JavaMappingRegistry();
mapper.load(mappings);

// 3. JavaContext'e bağla
const Java = createJavaContext(bridge, true, mapper);

// Artık tüm Mojang isimleri hedef JVM'de otomatik çözülür!
const BlockPos = Java.type('net.minecraft.core.BlockPos');
const pos = new BlockPos(100, 64, -200);
```

## İki Yönlü Çözümleme (Bi-Directional Resolution)

`JavaMappingRegistry` çift yönlü çalışır:

- **Obfuscated -> Deobfuscated:** Hedef JVM'den bir nesne örneği döndüğünde veya istisna fırlatıldığında, nesnenin sınıfı (`ave`) loglarda ve denetim araçlarında temiz isim (`net.minecraft.client.Minecraft`) olarak gösterilir.
- **Deobfuscated -> Obfuscated:** Geliştirici `Java.type()`, alan okuma veya metod çağırma yaptığında, temiz isim JNI katmanında hedefteki gerçek karıştırılmış ada çevrilir.
