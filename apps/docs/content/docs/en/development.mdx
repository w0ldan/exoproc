Exoproc is a Bun workspace monorepo targeting Windows x64. Linux development can run Windows Bun under Wine through `bun-wine`.

```bash
bun install
bun run build
bun run lint
bun run typecheck
bun test
```

The Next.js and Fumadocs application lives in `apps/docs`. Run it with `bun run docs:dev`, create a production build with `bun run docs:build`, and serve that build locally with `bun run docs:preview`. Cloudflare build and deployment commands are available as the `cf:*` scripts in `apps/docs/package.json`.
