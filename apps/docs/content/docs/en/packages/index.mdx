The Exoproc repository is organized as a Bun workspace monorepo consisting of modular packages targeting Windows x64:

| Package                | Responsibility                                                                                                                                 |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **`exoproc`**          | **Unified top-level package:** CLI runner (`exoproc run`), MCP server, automation daemon, and client with native Windows in-process execution. |
| **`bun-njava`**        | JVM reverse engineering, pure JNI vtable reflection, dynamic class proxying, and thread attachment.                                            |
| **`njava-agent`**      | In-process high-throughput Java agent with embedded HTTP/RPC loopback server for real-time tick automation.                                    |
| **`njava-runtime`**    | Runtime script execution, Nashorn compatibility shims (`Java.type`, `Java.from`, `Java.extend`), and class definer strategies.                 |
| **`exoproc-mappings`** | Multi-version mapping pool and database indexer (Mojang, Fabric Intermediary, Yarn, Forge MCP).                                                |
| **`exoproc-jjit`**     | Zero-dependency in-memory Java compiler (ECJ 3.26 for Java 8, ECJ 3.46 for Java 17+) and Tiny-Remapper.                                        |
| **`bun-xffi`**         | Foundational cross-process FFI: C ABI types, struct/union layout, memory accessors, and TinyCC JIT.                                            |
| **`bun-winapi`**       | Win32 process, thread, module, memory, and thread context wrappers.                                                                            |
| **`bun-nthread`**      | Stealth cross-process execution by redirecting an existing target thread without `CreateRemoteThread`.                                         |
| **`bun-nhook`**        | Allocation-free 2-byte inline `EB FE` park-and-simulate function redirection.                                                                  |
| **`bun-minhook`**      | Standard 5-byte relative JMP detour and relocated trampoline hooking with far-relay support.                                                   |
| **`bun-capstone`**     | Capstone disassembly bindings for instruction decoding and relative address relocation.                                                        |
| **`bun-nshm`**         | Inter-process shared memory helpers and synchronization primitives.                                                                            |
| **`exoproc-utils`**    | Common logging, error handling, and performance diagnostic utilities.                                                                          |

## Architectural Flow

```text
exoproc (Unified CLI, MCP & Automation)
  │
  ├─► njava suite (bun-njava, njava-agent, njava-runtime, exoproc-mappings, exoproc-jjit)
  │     └─► JVM Reflection, Dynamic Bytecode, Nashorn API & In-Process Agent
  │
  ├─► Hooking suite (bun-nhook, bun-minhook, bun-capstone)
  │     └─► Function Redirection (2-byte park & 5-byte JMP detours)
  │
  └─► Execution & Memory foundation (bun-nthread, bun-winapi, bun-xffi)
        └─► Thread Redirection, Win32 API, Memory Accessors & C-ABI
```
