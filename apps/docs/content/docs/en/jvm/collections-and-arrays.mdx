The `Java.from()` and `Java.to()` helper functions bridge Java data structures (`List`, `Set`, `Collection`, Java arrays) and native JavaScript arrays (`Array`).

Both utilities comply with standard Nashorn and GraalJS interfaces.

## Java to JavaScript: `Java.from()`

The `Java.from(javaObj)` function:

- Converts any Java `List`, `Collection`, `Iterable`, or array into a native JavaScript `Array<any>`.
- Automatically wraps contained Java objects in `JavaObjectProxy` instances or unboxes primitives to JS types.
- Enables standard JS methods such as `.map()`, `.filter()`, `.forEach()`, and `for...of` loops.

```typescript
const ArrayList = Java.type('java.util.ArrayList');
const list = new ArrayList();

list.add('Apple');
list.add('Banana');
list.add('Orange');

// Convert Java List to JS Array
const jsList = Java.from(list);

console.log(Array.isArray(jsList)); // true
console.log(jsList.length); // 3

// Use standard JS functional array methods
const upper = jsList.map((item) => item.toUpperCase());
console.log(upper); // ['APPLE', 'BANANA', 'ORANGE']
```

### Converting Java Arrays

Arrays returned from the JVM (`String[]`, `Object[]`, or primitive arrays like `int[]`) convert similarly:

```typescript
const StringClass = Java.type('java.lang.String');
const text = new StringClass('hello world exoproc');

// Java split returns String[]
const javaArr = text.split(' ');

// Convert to native JS Array
const jsWords = Java.from(javaArr);
console.log(jsWords); // ['hello', 'world', 'exoproc']
```

## JavaScript to Java: `Java.to()`

`Java.to(jsArray, targetType)` converts a JavaScript array into a Java array or collection in target JVM memory.

### 1. Creating Object Arrays

Specify the target type string to allocate typed arrays like `String[]` or custom class arrays:

```typescript
// Create Java String[]
const javaStringArray = Java.to(
  ['alpha', 'beta', 'gamma'],
  'java.lang.String[]',
);

// If targetType is omitted, defaults to Object[]
const defaultArray = Java.to(['one', 2, true]);
```

### 2. Creating Primitive Arrays

For high-performance I/O or memory buffers, Java requires primitive arrays (`byte[]`, `int[]`, `float[]`). `Java.to()` handles primitive allocation:

```typescript
// Primitive byte[]
const byteArray = Java.to([0x1f, 0x8b, 0x08], 'byte[]');

// Primitive int[]
const intArray = Java.to([100, 200, 300, 400], 'int[]');

// Primitive double[]
const doubleArray = Java.to([1.25, 3.1415, 9.8], 'double[]');
```

### 3. Converting to Collections

Pass a collection type name when a `List` or `ArrayList` is required instead of an array:

```typescript
const javaList = Java.to(['a', 'b', 'c'], 'java.util.ArrayList');
console.log(javaList.size()); // 3
```

## JNI Memory Allocation

Under the hood:

1. `ReflectionBridge` executes the corresponding JNI routine (`NewObjectArray`, `NewIntArray`, `NewByteArray`, etc.) to allocate the array on the remote JVM heap.
2. Elements are copied using `SetObjectArrayElement` or `SetIntArrayRegion`.
3. A wrapped `JavaObjectProxy` pointing to the allocated `jarray` is returned.
