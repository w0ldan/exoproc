---
title: 'Java.type & Dynamic Class Proxies'
description: 'Accessing target JVM classes via Java.type(), instantiating objects, overload resolution, and field access.'
---

The `Java.type(className)` function produces a **Dynamic Class Proxy** (`JavaClassProxy`) for any target JVM class. It adheres fully to standard Nashorn and GraalJS semantics.

Through the proxy, you can instantiate objects, invoke static and instance methods, read and write fields, and inspect reflection metadata.

## Loading Classes & Creating Instances

Classes are accessed using their fully qualified name (or deobfuscated name if mappings are registered):

```typescript
// Resolve class proxy
const ArrayList = Java.type('java.util.ArrayList');

// 1. Using the "new" operator
const list1 = new ArrayList();

// 2. Calling as a function (Nashorn style)
const list2 = ArrayList(10); // Initial capacity 10
```

### Constructor Overload Matching

When a Java class declares multiple constructors, Exoproc inspects argument counts and runtime types to automatically select the matching JVM constructor overload:

```typescript
const File = Java.type('java.io.File');

// Matches File(String pathname)
const file1 = new File('C:\\temp\\log.txt');

// Matches File(String parent, String child)
const file2 = new File('C:\\temp', 'data.bin');
```

## Method Invocations & Overload Resolution

Class and object proxies handle both static and member methods seamlessly:

```typescript
const Math = Java.type('java.lang.Math');

// Static method invocation
const maxVal = Math.max(10, 25); // 25
const sinVal = Math.sin(1.57);

// Member method invocation
const list = new ArrayList();
list.add('First Item');
list.add('Second Item');
console.log(list.size()); // 2
console.log(list.get(0)); // 'First Item'
```

Exoproc's overload matching engine (`matchMethodOverload`):

- Unboxes primitives (`int`, `long`, `boolean`, `double`, etc.) and handles wrappers (`Integer`, `Long`, etc.).
- Discriminates strings, general objects, and arrays.
- Selects the most specific candidate to invoke the target `jmethodID`.

## Field Access

Object and static fields are accessed via standard JavaScript property syntax (`.` operator):

```typescript
const Point = Java.type('java.awt.Point');
const pt = new Point(10, 20);

// Reading fields
console.log(pt.x); // 10
console.log(pt.y); // 20

// Writing fields (immediately updated in remote JVM memory)
pt.x = 99;
console.log(pt.x); // 99

// Static fields
const Integer = Java.type('java.lang.Integer');
console.log(Integer.MAX_VALUE); // 2147483647
```

## Nested & Inner Classes

Inner classes can be referenced using standard JVM `$` notation or navigated directly on the parent class object:

```typescript
// Standard JVM notation
const Entry = Java.type('java.util.Map$Entry');

// Or accessed directly from the outer class
const Map = Java.type('java.util.Map');
const InnerEntry = Map.Entry;
```

## Reflection Metadata & Pointer Unwrapping

Every proxy exposes reflection metadata:

```typescript
const StringClass = Java.type('java.lang.String');

console.log(StringClass.name); // "java.lang.String"
console.log(StringClass.superclass); // java.lang.Object proxy
console.log(StringClass.class.getName()); // "java.lang.String"
```

For low-level JNI interoperability, unwrap proxies to their raw 64-bit pointers (`jobject` or `jclass`):

```typescript
import { unwrapJava } from 'bun-njava';

const rawPtr: bigint = Java.unwrap(myInstance);
// or
const rawPtrDirect: bigint = myInstance.$ptr;
```
