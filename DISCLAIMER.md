**Exoproc** is an open-source systems engineering, diagnostics, and binary analysis framework designed exclusively for authorized, lawful purposes.

## 1. Authorized & Lawful Use Cases

Exoproc is created and maintained for:

- **Systems Engineering & Diagnostics:** Inspecting process memory, debugging live native applications, and diagnosing runtime performance or memory layout.
- **Authorized Security Research:** Security auditing, vulnerability research, and coordinated disclosure on software you own or have explicit written permission to test.
- **Academic & Educational Study:** Learning x86_64 calling conventions, Win32 API internals, JIT compilation mechanisms, and compiler code generation.
- **Interoperability & Software Preservation:** Analyzing legacy software structures to build open, interoperable tools and standards.
- **AI Agent Tooling:** Providing Model Context Protocol (MCP) capabilities for AI coding agents to assist developers in reverse engineering and debugging tasks.
